# DataStructs — Interactive Data Structures Lab & Arcade

An interactive web application featuring real-time visual simulations and gamified challenges for learning computer science data structures.

## 🚀 Features

- **6 Core Data Structures**:
  - **Arrays**: Contiguous memory model, shifting animations, linear & binary search, two-pointer reversal.
  - **Binary Search Trees (BST)**: SVG tree visualizer, path tracing, node insertion & deletion, In-Order, Pre-Order, Post-Order, and Level-Order traversals.
  - **Stacks (LIFO)**: Vertical stack frame, animated Push & Pop, syntax delimiter checking (`{[()]}`).
  - **Queues (FIFO)**: Linear queue & circular ring buffer with modulo arithmetic (`(rear + 1) % capacity`).
  - **Linked Lists**: Singly & Doubly-linked chains, pointer reversal, Floyd's Tortoise & Hare cycle detection.
  - **Graphs**: Weighted network graph, BFS queue wave, DFS call stack, Dijkstra shortest path.
- **6 Dedicated Learning Games**: Gamified challenges with levels, streaks, combos, and sound feedback.
- **Web Audio API**: Browser-synthesized sound effects with mute toggle.
- **Big-O Complexity Matrix**: Worst-case analysis and real-world software engineering applications.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port specified in terminal).

### 3. Build for Production
```bash
npm run build
```
Preview the production build:
```bash
npm run preview
```
